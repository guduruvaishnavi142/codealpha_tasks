# 🤖 KITSW College FAQ Chatbot

## 📌 Project Overview

The **KITSW College FAQ Chatbot** is a simple and interactive chatbot developed as part of the **CodeAlpha Internship – Task 2: Chatbot for FAQs**.

The project is designed to provide quick answers to frequently asked questions related to KITSW College through an easy-to-use chatbot interface.

## 🎯 Objective

The main objective of this project is to create an FAQ-based chatbot that can receive questions from users and provide relevant answers from a predefined FAQ dataset.

## ✨ Features

- 🤖 Interactive FAQ chatbot
- 💬 Simple and user-friendly chat interface
- 📚 Predefined college FAQ dataset
- 🔎 Question matching and relevant answer retrieval
- ⚡ Quick responses
- 🖥️ Easy-to-use interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Natural Language Processing concepts
- FAQ-based question matching

## 🔄 How the Chatbot Works

1. The user enters a question in the chatbot.
2. The chatbot processes the entered question.
3. The question is compared with the available FAQ questions.
4. The most relevant FAQ is identified.
5. The corresponding answer is displayed to the user.
